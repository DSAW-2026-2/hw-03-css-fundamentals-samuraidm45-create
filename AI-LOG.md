# Bitácora de IA

Durante el desarrollo de esta tarea utilicé inteligencia artificial como apoyo para organizar y revisar el código CSS.

Uno de los problemas principales fue organizar correctamente los estilos responsive. Al principio los estilos base y las reglas para diferentes tamaños de pantalla estaban mezclados en un solo archivo. La IA me explicó que separar los estilos principales en `main.css` y las reglas responsive en `responsive.css` hace que el código sea más fácil de mantener y permite controlar mejor los breakpoints.

También utilicé IA para revisar la distribución de los elementos utilizando Flexbox y CSS Grid. La explicación fue que Grid es más conveniente para las tarjetas de películas porque permite controlar filas y columnas, mientras que Flexbox funciona mejor para elementos que necesitan organizarse principalmente en una dirección, como la navegación y los formularios.

Para la sección de preguntas frecuentes también utilicé IA como apoyo. Aprendí que se puede crear un acordeón sin JavaScript utilizando enlaces con `href` y el selector CSS `:target`. Cada pregunta apunta a un elemento mediante su `id` y CSS muestra la respuesta cuando ese elemento se convierte en el elemento objetivo.

Después de recibir las explicaciones, adapté el código a la estructura de mi proyecto CineHub.
